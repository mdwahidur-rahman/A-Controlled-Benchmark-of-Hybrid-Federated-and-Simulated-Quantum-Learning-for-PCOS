# Results shipped with the repository

`tables/*.csv` are the aggregate outputs that every number in the manuscript is generated from (point estimates and 95 percent group-cluster bootstrap intervals; no patient-level or image-level predictions).

| File family | Content |
|---|---|
| `main_results.csv`, `partition_and_preprocessing_tests.csv`, `baselines_*_summary.csv`, `gap_to_size_only_baseline.csv` | Eleven frozen encoders, three partition rules, three preprocessing variants, no-pixel references |
| `tuning_*.csv` | Validation-tuned heads, soft-vote ensembles, sensitivity |
| `fl_*.csv` | Federated partitions, algorithms, group-level DP |
| `quantum_*.csv` | Noiseless simulated quantum slot, controls, tuning grids, final runs |
| `xai_*.csv`, `gradcam_faithfulness.csv` | Explanation faithfulness and agreement |
| `performance_*.csv` | 13 metrics, confusion counts, paired contrasts with Holm adjustment |
| `calibration_*.csv` | Expected calibration error, reliability bins, paired ECE contrasts |
| `encoder_rank_stability.csv`, `roc_operating_points.csv` | Post-hoc summaries (`pipeline/32_extra_stats.py`): rank correlation of encoders between preprocessing variants; sensitivity at 95 and 99 percent specificity and average precision |

`stage0_audit.json`, `stage1_splits.json`, `quantum_final_plan.json`, `quantum_selftest.json` hold the dataset audit, split summary, selected quantum configurations and the simulator self-tests. `fl/tuned_<encoder>.json` hold the validation-selected federated and group-level-DP settings of the three federated encoders.

Not shipped (large): the per-image probability files (`results/heads`, `tuning`, `fl/runs`, `quantum_final`), cached features and explanation maps. They are regenerated by the pipeline or can be archived with a DOI by the authors \[ARCHIVE DOI REQUIRED\].
